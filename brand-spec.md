## Typography

- Display and editorial statements: `"Newsreader", Georgia, serif`
- Body, navigation, controls: `"Familjen Grotesk", "Avenir Next", "Helvetica Neue", sans-serif`
- Labels, metadata, annotations: `"IBM Plex Mono", monospace`

## Posture

1. Build asymmetric, unequal-but-balanced columns on visible alignment lines.
2. Lead with real project evidence; label unavailable screenshots honestly.
3. Pair large editorial serif statements with practical sans-serif explanation and mono implementation notes.
4. Use selective crop, overlap, and annotation without covering text or focal subjects.
5. Reserve coral for action, cobalt for project windows, acid for focus/availability, and teal for compact system feedback.
